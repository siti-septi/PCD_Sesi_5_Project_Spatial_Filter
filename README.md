
# PROJECT PCD SESI 5 - SPATIAL FILTERING

## Deskripsi
Project ini merupakan implementasi Spatial Filtering
pada citra digital menggunakan Python.

Citra yang digunakan adalah foto objek kunci
dengan nama file image.jpg.

## Metode Filtering
1. Mean Filter 3x3
2. Mean Filter 5x5
3. Gaussian Filter 3x3
4. Gaussian Filter 5x5
5. Median Filter 3x3
6. Median Filter 5x5
7. Sharpening Filter

## Teknologi
- Python
- NumPy
- ImageIO
- Matplotlib
- SciPy

## Instalasi Library

```bash
pip install imageio numpy matplotlib scipy
```

## Cara Menjalankan

```bash
python main.py
```

## Hasil Pengujian

Seluruh hasil filtering dan nilai intensitas
tersimpan dalam folder output.
